How Downlink Control Works

When the remote USR-DR302 establishes an outbound TCP connection to this server, the TCP socket is held permanently open via NAT keepalive heartbeats.

  • Instant Transmission: Any bytes sent through this console are delivered instantly across the WAN to the DR302 unit.
  • Transparent RS485 Output: The DR302 converts the network packet back into electrical RS485 differential signals for your downstream meters, inverters, or sensors.
  • Automatic Response Capture: When the RS485 slave replies, the DR302 sends the response back over the same TCP link, which is automatically decoded and displayed in the Telemetry Terminal!

PUSR USR-DR302 Hardware Configuration Wizard

Exact configuration steps for your physical USR-DR302 web console to connect without VPN

Server Network Interfaces Detected:

💡 For remote sites across the public Internet, enter your Public IP / Dynamic DNS domain / Cloud VPS IP into the DR302 Remote Server IP field.

1

Initial Access to USR-DR302

Connect your computer directly to the DR302 LAN port or plug it into your local network switch.

Default Web IP:192.168.0.7
Default Subnet:255.255.255.0
Default Gateway:192.168.0.1
Default Username:admin
Default Password:admin
2

Mode A: Configure as TCP Client (Recommended for No-VPN)

Go to Local IP Config / Network -> Work Mode in the DR302 web console:

Work Mode:TCP Client
Remote Server IP/Domain:YOUR_SERVER_PUBLIC_IP
Remote Port:5000
Local Port:0 (Auto dynamic)
Heartbeat Packet:Enable -> Set time to 15s, Data: www.usr.cn (Maintains NAT state)
Registration Packet:Enable -> Select "Connect with MAC" or "Connect with User Data" (e.g. DR302_SUBSTATION_01)
Why TCP Client? Because the remote DR302 connects OUTBOUND to the central server. Routers and cellular 4G modems automatically permit outbound TCP traffic and map NAT ports, eliminating the need for expensive VPNs or static public IPs at the remote sites!
3

Mode B: Configure as HTTPD Client (Web REST Mode)

If your remote site only allows standard web traffic (Port 80/443/3000):

Work Mode:HTTPD Client
URL Path:/api/telemetry
Remote Server IP/Domain:YOUR_SERVER_PUBLIC_IP
Remote Port:3000
HTTP Header:X-Device-ID: DR302_BRANCH_01
4

RS485 Serial Port Parameters

Under Serial Port Settings, match your connected Modbus meter, PLC, or RS485 sensor:

Baud Rate:9600 (or matching your sensor, e.g. 19200, 115200)
Data Size:8
Parity:None (or Even/Odd matching your slave)
Stop Bits:1
Modbus Gateway:Set to "Modbus RTU" or "None (Transparent)"
5

No-VPN WAN Deployment Strategies

Option 1: Router Port Forwarding

If hosting this server on a local office machine with a public broadband connection:

  • Log in to your office router's admin page.
  • Add Port Forwarding rules:
    TCP 5000 -> Server Local IP:5000
    UDP 5001 -> Server Local IP:5001
    TCP 3000 -> Server Local IP:3000

Option 2: Cloud VPS (AWS / DigitalOcean / Hetzner)

Run this Node.js app directly on a cheap $4/mo Linux VPS:

  • Has a fixed public static IP immediately.
  • Remote DR302s can connect directly 24/7 without router NAT worries.

Option 3: Zero-Config Cloudflare Tunnel / ngrok

For instant testing without changing router firewall:

  • Use ngrok tcp 5000 for TCP testing or Cloudflare Tunnel.
